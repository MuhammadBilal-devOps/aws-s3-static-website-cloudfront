# AWS Static Website Hosting using S3 + CloudFront

## Project Overview
I implemented a cloud project where I hosted a static website using AWS services.

## Technologies Used

- Amazon S3
- Amazon CloudFront
- Static Website Hosting
- CDN (Content Delivery Network)

## Project Steps

1. Created an S3 bucket and uploaded HTML website files
2. Enabled Static Website Hosting
3. Configured bucket permissions for public access
4. Created a CloudFront distribution
5. Connected CloudFront with the S3 bucket
6. Accessed the website using CloudFront URL
